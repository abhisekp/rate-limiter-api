THE SMALL THING THAT HELPS

Make every request count.

Give the limiter your provider’s quota headers. It reserves capacity as work starts, holds queued calls when the budget runs out, and resumes when the provider window resets.

01 / SET THE RULES
concurrency: 2

Choose your pace

Set a safety threshold, concurrency, and a burst first or uniform strategy.

02 / QUEUE YOUR WORK
→0102

Send without guessing

Hand each operation to limit(). The scheduler dispatches only what the budget allows.

03 / KEEP MOVING
◷reset

Resume at reset

When the provider’s window opens again, the waiting queue continues on its own.

// Queue a request and keep a little quota in reserve
const limiter = RateLimiterAPI({
  threshold: 1,
  concurrency: 2,
})

limiter.updateRateLimits({
  rateLimit: 60,
  rateRemaining: 42,
  rateReset: Date.now() + 60_000,
})

const result = await limiter.limit(() => fetch('/api/data'))
